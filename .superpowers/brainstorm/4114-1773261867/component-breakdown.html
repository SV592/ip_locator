Component Architecture

New and modified components for the overhaul

New Components

src/app/components/ — additions

HUD Layer (HTML overlays)

HUD.tsx — container, positions all panels
TargetPanel.tsx — left panel: IP, hostname, location, org
StatsPanel.tsx — left panel: hop count, avg RTT, countries
HopList.tsx — right panel: scrollable hop list, click to select
CommandBar.tsx — bottom bar: status, replay, history
SearchBar.tsx — replaces IPTracker, top-center pill

State

store/traceStore.ts — Zustand store for all shared state

Mobile Fallback

MobileView.tsx — 2D map + card-based hop list
DeviceGate.tsx — detects WebGL, routes to 3D or 2D

3D Scene (R3F children)

HopMarkers.tsx — instanced glowing spheres at hop locations
RouteArcs.tsx — great-circle arcs between hops, animated draw
CameraController.tsx — smooth fly-to on hop select, auto-tour
HopTooltip.tsx — HTML overlay on hover (drei's Html)
PulseRing.tsx — expanding ring effect at active hop

Optimized Replacements

Countries.tsx — rewritten: TopoJSON, merged BufferGeometry
States.tsx — same optimization as Countries

API Changes

api/trace/route.ts — rewrite to SSE streaming
hooks/useTrace.ts — client hook for SSE consumption

Modified vs Deleted

Modified
Scene.tsx — add CameraController, HopMarkers, RouteArcs as children
Earth.tsx — add error boundary, progressive texture loading
page.tsx — integrate HUD overlay, DeviceGate, Zustand provider
Replaced
IPTracker.tsx → SearchBar.tsx (same concept, new design)
Hop.tsx → HopList.tsx + HopMarkers.tsx (split UI from 3D)
