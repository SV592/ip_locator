Design Overview — IP Locator Overhaul

Three phases, interleaved. Each phase is a shippable milestone.

Phase 1: Foundation + Core Traceroute

Performance fixes alongside basic hop visualization

What gets built

🔧 Performance

  • Replace 14.6 MB countries.json with TopoJSON (~1.5 MB)
  • Add loading skeleton + suspense boundaries
  • Error boundaries around 3D scene
  • Lazy-load textures with progressive resolution
  • LOD system — simplified geometry when zoomed out

📍 Core Traceroute

  • Hop markers on globe (glowing dots at geolocations)
  • Sequential arc paths connecting hops (great-circle arcs)
  • Wire up IPTracker → API → Globe pipeline end-to-end
  • Stream partial results (show hops as they resolve)
  • Basic HUD panel showing hop list with RTT

Phase 2: Cinematic Viz + Full Optimization

Camera animations, interactive arcs, rendering polish

What gets built

🎬 Cinematic

  • Camera fly-through: auto-animates hop to hop
  • Animated arc drawing (path traces in real-time)
  • Pulse/ripple effect at each hop marker
  • Globe auto-rotates to show route on submit
  • Particle trail along arcs (data flow visualization)

⚡ Optimization

  • Instanced rendering for hop markers
  • Geometry merging for country borders
  • Frustum culling for off-screen elements
  • Texture atlas for celestial bodies
  • RequestAnimationFrame budget management

Phase 3: UX Polish + Mobile Fallback

Interactive exploration, history, and graceful degradation

What gets built

🖱️ Interactive UX

  • Click hop in sidebar → camera flies there
  • Hover hop marker → tooltip with details
  • Search history (localStorage)
  • Compare routes side-by-side (multi-trace)
  • Country/ASN filtering and grouping
  • Export route data (JSON/image)

📱 Mobile Fallback

  • Detect WebGL/device capability
  • 2D map fallback (Leaflet or static SVG)
  • Card-based hop list for small screens
  • Touch-friendly input and results
  • Reduced data payloads for mobile
